# Hybrid Matrix portfolio — approved design

## Direction

Return the Red experience to a cinematic portfolio layout with clear spacing and hierarchy. Terminal and Matrix language become an interaction layer, not the page container.

## Composition

- Each scene lives on the Matrix background without a full-screen terminal frame.
- Large editorial headings establish hierarchy and are followed by one focused content surface.
- Terminal controls are compact docks containing command history, input, and contextual choices.
- Experience, projects, and stack keep distinct visual compositions instead of sharing one large repeated shell.
- Existing keyboard commands, typed commands, and free scrolling remain available.

## Visual balance

- Use dark translucent surfaces only around focused content and terminal controls.
- Preserve generous negative space between scenes.
- Keep scan lines, green strokes, cursor blink, and status signals as restrained accents.
- Avoid full-height borders, page-wide terminal chrome, repeated heavy frames, and dashboard density.

## Acceptance criteria

- No scene reads as a giant terminal window.
- Headings and professional content are visually primary.
- Terminal interaction remains obvious but secondary.
- Desktop and mobile preserve readable spacing without horizontal overflow.
