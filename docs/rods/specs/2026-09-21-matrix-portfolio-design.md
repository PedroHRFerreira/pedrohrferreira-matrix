# Matrix Portfolio — Approved Design

## Product

A bilingual professional portfolio that begins inside a physical retro television and a single Red/Blue choice.
Both realities expose equivalent professional information through distinct art directions.

## Experience contract

- State flow: booting → identifying → choosing → transition → selected portfolio.
- Reality lives in memory only and resets on reload.
- Locale can change without remounting the selected reality.
- Red and Blue share typed content, not forced visual components.
- Contact uses direct professional links and no backend.
- Entry timing is fixed: 0–3s analog static, 3–3.7s signal lock, 3.7–4.7s geometric screen expansion.
- The question and pill controls first appear inside the television screen; the same screen becomes the viewport without a cut or page reload.
- The locale control must remain subtle, compact and secondary to the Matrix narrative.

## Visual thesis

Red reveals the system through restrained terminal language, depth, and low-contrast code rain.
Blue presents an airy manufactured calm whose rare green faults reveal the system underneath.
Motion supports the narrative, degrades cleanly for reduced-motion and never gates content. The intro uses a restrained realistic 4:3 television shell, grayscale analog noise and a continuous screen-to-viewport expansion instead of a generic glowing panel.

## Acceptance

Keyboard and touch support, responsive layouts, reduced-motion fallbacks, localized content,
SEO metadata, focused GSAP timelines, passing lint/test/build, and browser validation for both
realities on desktop and mobile.
